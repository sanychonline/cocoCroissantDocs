# Coco Croissant Docs

Public product and support site for **Coco Croissant** / **Цуценя Круасан**. The character is **Цуценя Круасан**, catching falling croissants in a three-lane arcade game.

## Site content

- Uses Coco Croissant app assets: character, croissants, game background, icon, and logo.
- Keeps the Parisian blue-and-gold palette consistent on `index.html`, `support.html`, `privacy.html`, and `terms.html`.
- Shows the approved Docs screenshots: launch art without a spinner, active gameplay with falling croissants and no Game Over or banner, and English settings.
- Provides localized support in 17 interface languages.

## Deployment

The static public site deploys from `main` through `.github/workflows/pages.yml`.
